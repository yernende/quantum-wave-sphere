# Repository Instructions

## English-only

All repository content, file names, and directory names must be written in
English. This includes source code, comments, documentation, configuration,
tests, user-facing text, commit messages, and newly created files.

## C++ Style

Prioritize idiomatic, modern C++23 in all code. Prefer RAII, value
semantics, explicit ownership, const-correctness, type-safe interfaces, and the
standard library. Use modern language and library features when they improve
clarity, safety, or maintainability, not merely because they are new. Avoid
clever code, unnecessary abstractions, and premature infrastructure.
